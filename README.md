# Arc-2026
Rules-based finishing-order predictor for the 2026 Prix de l'Arc de Triomphe. Run `python3 arc_2026_predictor.py`. See MEMORY.md (facts, caveats) and PLAN.md (next steps).
Layout: each prediction iteration lives in versions/vN/ (predictor.py + PREDICTION.md). Latest script also at arc_2026_predictor.py. See PREDICTION_HISTORY.md for the comparison.
